# koishi-plugin-mars-images

QQ群图片火星检测koishi插件。记录窗口内群友发的图，重复发图就提示「火星」，并统计每人火星次数。
仅供自用，本人不懂前端代码完全由ai编写

## 功能

1. 记录一段时间内(可配置1-7天)群友发送的图片
2. 有人发重复图(可配置相似度超阈值),bot 提示是「何时、哪个群友」先发过
3. 每次火星给发图者计数
4. 发送统计文本(可配置),bot 输出群友火星次数排行

## 安装

```bash
npm install
npm run build
```

插件入口 `lib/index.js`。在 Koishi 控制台:

1. 启用数据库驱动 `@koishijs/plugin-database-sqlite`(本插件依赖 `database` 服务)
2. 依赖管理中安装jimp

## 配置项

| 键 | 默认值 | 说明 |
|----|--------|------|
| `windowDays` | `7` | 图片记录窗口(天),1-7 |
| `threshold` | `90` | 重复判定相似度阈值(%) |
| `notify` | `true` | 火星时是否发提示;`false` 静默记录,仍累计次数 |
| `minImageBytes` | `0` | 图片最小体积(KB),宽高不达标时检查;`0` 表示宽高不达标时也不限制体积 |
| `minImageWidth` | `360` | 图片最小宽度(像素),必须大于 0 |
| `minImageHeight` | `360` | 图片最小高度(像素),必须大于 0 |
| `marsMessage` | `{at} 火星了！这张图 {time} 由 {user} 发过（你已 {count} 次）` | 火星提示语 |
| `statsCommand` | `火星统计` | 触发统计的文本 |
| `statsHeader` | `🔥 火星次数统计：` | 统计标题 |
| `statsEmpty` | `还没有人火星过` | 无人火星时提示 |
| `statsRow` | `{user}：{count} 次` | 统计每行 |

占位符:`{at}` @对方、`{user}` 原发送者、`{time}` 原发送时间、`{count}` 对方累计次数。

## 实现说明

- 图片相似度用 **dHash(差值感知哈希)**:灰度化 → 缩放 9×8 → 逐行相邻像素比较,得到 64 位哈希。`相似度 = (64 - 汉明距离) / 64`。
- 下载图片用 `ctx.http.get` 抓 `url`/`src`/`file`(支持 `base64://`)。
- 数据存 Koishi 数据库(需启用 sqlite 驱动),两张表:`mars_image`(图片哈希记录)、`mars_count`(火星次数)。重启保留。
- 同一哈希只保留「首次发送者 + 时间」作为火星对象,不重复记录。
- `face`、`emoji` 等原生表情默认忽略,不下载、不哈希、不计数。
- 图片过滤同时作用于普通消息和转发卡片:先按字节数过滤,再按解码后的宽高过滤。

## 已知限制

- 部分 QQ 图片 URL 需适配器注入 Cookie 才能下载,`ctx.http` 直接抓取可能失败;失败时该图被跳过。
